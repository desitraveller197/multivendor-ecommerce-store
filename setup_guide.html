Developer Operations Guide

Bazarix Multivendor Store

A step-by-step setup guide to packaging, running, and configuring the e-commerce application for sharing.

1 System Prerequisites

Before running the application, make sure your friend has the following software installed on their machine:

Node.js
Version v18.0.0 or higher is required to compile React 19 / Vite 8 components.
MongoDB
A local MongoDB instance (port 27017) or a MongoDB Atlas Cloud connection string.
Package Manager
npm (pre-bundled with Node.js) to retrieve backend and client dependencies.

2 How to Package the Project

To package the project into a compact `.zip` file for sharing, follow these rules:

⚠️ IMPORTANT WARNING: Do NOT include the node_modules/ directories inside either the root, server/, or my-project/ folders. These folders contain compiled system dependencies and can exceed 500MB in size. Excluding them keeps the zip file under 15MB.
multivendor-ecommerce-store/
├── images_clean/            # Include: clean product seed images
├── my-project/              # Include (except node_modules)
├── output/                  # Include: contains products.json catalog
├── server/                  # Include (except node_modules and uploads)
└── setup_guide.html        # Include this guide

4 Installation and Launch Guide

Follow these commands to install the dependencies, seed the database, and launch both frontend and backend development servers.

  1. A
    Install Packages

    Open two separate terminals and navigate into the respective directories to run npm install:

    # Terminal 1: Backend
    cd server
    npm install
    # Terminal 2: Frontend
    cd my-project
    npm install
  2. B
    Seed Database Products

    To pre-populate categories, admin/customer accounts, shops, and upload product photos to Cloudinary, run the seed commands inside the server/ folder:

    cd server
node seed/seedDatabase.js
node seed/seedSindhiProducts.js
    Note: Seeding script will automatically read from output/images_clean/ and upload those product images directly to Cloudinary.
  3. C
    Start the Application Servers

    In your two open terminal sessions, start the development instances:

    # Terminal 1: API Server
    cd server
    node server.js
    # Terminal 2: Web App
    cd my-project
    npm run dev

    Once running, open http://localhost:5173/ in your web browser to browse the storefront!
